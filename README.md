# Miniweb de la ruta por Córdoba

Proyecto React + Vite con un itinerario vertical de dos días. Cada parada lleva a Google Maps y los dos billetes PDF originales están dentro de `public/billetes/` para tenerlos a mano desde la sección **Tus billetes**.

## Ejecutar en tu ordenador

1. Instala Node.js si todavía no lo tienes.
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev` y abre la dirección local que aparece en la terminal.

Para generar el sitio estático, ejecuta `npm run build`. La carpeta resultante será `dist/`.

Los enlaces a Google Maps necesitan conexión a Internet. Los PDF se sirven desde esta web local. Conserva privados los archivos de billetes si compartes o publicas el proyecto.
